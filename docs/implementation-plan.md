# 実装計画

## フェーズ1：基盤

- リポジトリ作成
- React、Hono、TypeScript環境構築
- SQLite、Drizzle導入
- Raspberry Pi上での起動確認
- Caddyまたはnginx設定
- Python認証アプリは別リポジトリで管理する前提を維持

## フェーズ2：入退室イベント

- people、access_events作成
- 入退室イベントAPIのBearerトークン認証
- 入退室イベント登録API
- eventIdによる冪等性
- 別リポジトリのPython認証アプリからの送信確認

## フェーズ3：在室状況・履歴

- occupancy_states作成
- 入室・退室による在室状態更新
- 日別入退室履歴API
- React管理画面

## フェーズ4：管理機能

- 管理者ログイン
- 利用者管理
- 監査ログ
- CSV出力

## フェーズ5：運用対策

- systemd登録
- 自動再起動
- バックアップ
- ログ管理
- NTP同期
- UPS・電源断対策

## フェーズ6：テスト

- 単体テスト
- APIテスト
- E2Eテスト
- 再送テスト
- 再起動テスト
- 復元テスト

## 優先順位

1. 入退室イベントを失わないこと
2. 二重登録を防ぐこと
3. Raspberry Pi再起動後に自動復旧すること
4. 管理画面から在室状況を確認できること
5. 入退室履歴を安全に検索・出力できること
