# 認証・セキュリティ

## 管理画面

- Cookieベースのセッション認証
- Cookieに`HttpOnly`を設定
- HTTPS利用時は`Secure`を設定
- `SameSite=Lax`を基本とする
- パスワードはArgon2またはbcryptでハッシュ化する

## 入退室イベントAPI

- 入退室イベント送信元は単一のRaspberry Piを想定する
- 端末の登録・無効化・個別管理は行わない
- `Authorization: Bearer <token>` による簡易認証を行う
- トークンは環境変数などで管理する
- トークンはリポジトリへコミットしない

## 認可

- 管理者
- 編集可能ユーザー
- 閲覧専用ユーザー

の権限を分ける。

## API保護

- 入力値をZodで検証する
- レート制限を設ける
- Bearerトークンが不正なリクエストを拒否する
- 操作ログを保存する
- エラー応答に内部情報を含めない

## ネットワーク

- 原則としてLAN内からのみアクセス可能にする
- Raspberry Piの不要ポートを閉じる
- SSHは鍵認証を推奨する
- 管理画面へのアクセス元を制限できる構成にする

## 個人情報

- 顔画像をAPIやDBへ保存しない方針を基本とする
- 保存する場合は保存期間と閲覧権限を定める
- バックアップにも同等のアクセス制御を適用する
