# 認証・セキュリティ

## 管理画面

- Cookieベースのセッション認証
- Cookieに`HttpOnly`を設定
- HTTPS利用時は`Secure`を設定
- `SameSite=Lax`を基本とする
- パスワードはArgon2またはbcryptでハッシュ化する

## 認証端末

- 端末ごとのAPIキーを発行する
- APIキーはDBへ平文保存しない
- APIキーのハッシュを保存する
- 無効化・再発行を可能にする

## 認可

- 管理者
- 編集可能ユーザー
- 閲覧専用ユーザー

の権限を分ける。

## API保護

- 入力値をZodで検証する
- レート制限を設ける
- 不正な端末IDを拒否する
- 操作ログを保存する
- エラー応答に内部情報を含めない

## ネットワーク

- 原則としてLAN内からのみアクセス可能にする
- Raspberry Piの不要ポートを閉じる
- SSHは鍵認証を推奨する
- 管理画面へのアクセス元を制限できる構成にする

## 個人情報

- 顔画像をAPIやDBへ保存しない方針を基本とする
- 保存する場合は保存期間と閲覧権限を定める
- バックアップにも同等のアクセス制御を適用する
