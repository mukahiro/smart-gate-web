# 要件定義

## 目的

顔認証またはカード認証により研究室メンバーを識別し、研究室への入室・退室を記録・閲覧できるローカルネットワーク向けWebシステムを構築する。

このシステムの主目的は、自分の研究室への出入りを記録することである。管理者が出欠を監視するためのものではなく、欠席や遅刻を記録・判定する必要はない。

## 利用者

- 研究室メンバー
- システム管理者または運用担当者
- 入退室イベント送信元のRaspberry Pi

## 機能要件

### 認証記録

- 顔認証結果を受信できる
- カード認証結果を受信できる
- 入室・退室イベントを記録できる
- 同一イベントの重複登録を防止できる
- 別リポジトリの認証アプリから再送されたイベントを冪等に処理できる

### 入退室記録

- 現在の在室状況を表示できる
- 日別の入退室履歴を表示できる
- 利用者ごとの履歴を表示できる
- 入室・退室の時刻を確認できる

### 利用者管理

- 利用者を登録・編集・無効化できる
- 顔認証用IDとカードIDを紐付けられる
- 所属情報を管理できる

### 管理画面

- ログインできる
- 現在の在室状況を確認できる
- 日付や利用者を指定して入退室履歴を検索できる
- CSV形式で出力できる

## 非機能要件

- Raspberry Pi上で動作する
- LAN内で利用できる
- インターネット接続がなくても基本機能が動作する
- 電源断やプロセス停止後に自動復旧できる
- 入退室イベントを失わない
- 個人情報へのアクセスを制限する
- 日常運用で手動操作を最小限にする

## 対象外

- 顔認証アルゴリズム自体の開発
- クラウド公開
- 不特定多数向けの利用
- スマートフォンアプリ
- 入退室イベント送信元の登録・無効化・個別管理
- 出席・欠席・遅刻の記録や判定
- 管理者による出欠監視
