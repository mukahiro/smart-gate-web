# 要件定義

## 目的

顔認証またはカード認証により利用者を識別し、出席・退席情報を記録・閲覧できるローカルネットワーク向けWebシステムを構築する。

## 利用者

- 管理者
- 教職員または運用担当者
- 認証対象者
- 認証イベント送信元のRaspberry Pi

## 機能要件

### 認証記録

- 顔認証結果を受信できる
- カード認証結果を受信できる
- 出席・退席イベントを記録できる
- 同一イベントの重複登録を防止できる
- API送信失敗時に再送できる

### 出欠管理

- 日別の出欠状況を表示できる
- 利用者ごとの履歴を表示できる
- 出席、遅刻、欠席、退席を判定できる
- 管理者が出欠情報を修正できる
- 修正履歴を残せる

### 利用者管理

- 利用者を登録・編集・無効化できる
- 顔認証用IDとカードIDを紐付けられる
- 所属情報を管理できる

### 管理画面

- ログインできる
- 本日の出席状況を確認できる
- 日付を指定して履歴を検索できる
- CSV形式で出力できる

## 非機能要件

- Raspberry Pi上で動作する
- LAN内で利用できる
- インターネット接続がなくても基本機能が動作する
- 電源断やプロセス停止後に自動復旧できる
- 認証イベントを失わない
- 個人情報へのアクセスを制限する
- 日常運用で手動操作を最小限にする

## 対象外

- 顔認証アルゴリズム自体の開発
- クラウド公開
- 不特定多数向けの利用
- スマートフォンアプリ
- 認証端末の登録・無効化・個別管理
