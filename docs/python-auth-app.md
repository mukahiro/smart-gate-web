# Python認証アプリ連携メモ

Python認証アプリは別リポジトリで管理する。このリポジトリでは実装しない。

この文書は、Web/API側が受け入れるイベント仕様を共有するための暫定メモとする。

## 責務

- 顔認証
- カード認証
- 利用者IDの特定
- 認証結果の生成
- Hono APIへの送信
- 送信失敗時の再送

## API送信データ

- eventId
- personId
- deviceId
- method
- eventType
- authenticatedAt
- confidence

## 再送キュー

- 認証成功時にイベントをローカル保存する
- API送信に成功したら削除する
- 失敗した場合は一定間隔で再送する
- 再起動後も未送信イベントを保持する

## 重複防止

- 同一人物を短時間に何度も送信しない
- eventIdを毎回発行する
- 最終的な重複判定はHono API側で行う

## 障害時

- API停止中も認証イベントを失わない
- ログへ送信失敗理由を記録する
- 復旧後に自動再送する
