# テスト方針

## 単体テスト

- 出欠判定
- 遅刻判定
- 重複イベント判定
- 権限判定
- 入力検証

## APIテスト

- 認証イベント登録
- 不正なAPIキー
- 重複eventId
- 無効なpersonId
- 出欠一覧取得
- 出欠修正
- CSV出力

## フロントエンドテスト

- ログイン
- 出欠一覧表示
- 検索
- 利用者登録・編集
- エラー表示
- 権限別表示

## 結合テスト

- Python認証アプリからHono APIへの送信
- APIからSQLiteへの保存
- Reactへの反映
- API停止後の再送
- Raspberry Pi再起動後の自動復旧

## 障害テスト

- ネットワーク切断
- API停止
- DBロック
- 電源断
- ストレージ容量不足
- 時刻ずれ

## 受け入れ基準

- 認証イベントが失われない
- 同一イベントが二重登録されない
- 再起動後に自動復旧する
- 権限のない操作が拒否される
